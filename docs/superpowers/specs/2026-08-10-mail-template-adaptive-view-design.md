# 邮件模板自适应工作区设计

## 目标

让大尺寸表格在 RestX 的编辑区和预览区中更容易观察、编辑和对照。所有缩放只作用于 RestX renderer 的显示层，不写入邮件 HTML，不改变模板数据、Outlook 字号或实际发送效果。

本次不处理尚无截图的合并单元格显示异常和行间小方格问题。

## 自适应显示

- 编辑区和预览区默认使用“自动适应”。
- 每个区域根据自己的可用宽度和正文中最宽表格的自然宽度独立计算显示比例。
- 比例计算结果限制在 `60%～100%`：能完整容纳时保持 `100%`；极宽表格最低缩到 `60%`，剩余宽度继续横向滚动，避免文字不可读。
- 窗口尺寸、工作区模式或正文表格尺寸变化时自动重新计算。
- 只缩放正文显示面；富文本工具栏、标题栏、保存按钮和 Outlook 操作保持正常尺寸。
- 标题区显示当前状态和实际比例，例如“自动 72%”；用户可以切换到“实际大小 100%”，并可重新启用自动适应。
- 没有表格时固定使用 `100%`。

## 单区展开模式

- 普通页面保持现有三栏布局。
- 从编辑区点击“展开”时进入“仅编辑”；从预览区点击“展开”时进入“仅预览”。
- 展开后不再同时显示编辑和预览：目标区域独占整个 RestX 主内容区，另一侧完全隐藏。
- “仅编辑”状态提供“切换到预览”和“退出专注”；“仅预览”状态提供“切换到编辑”和“退出专注”。普通页面本身承担并排对照用途，不额外提供“并排展开”。
- 模式切换不重建编辑器，不丢失未保存内容、选择状态或滚动状态；`Escape` 退出专注并恢复普通布局。

## 实现边界

- 改动仅限 `src/features/mail-template/renderer/` 及对应 renderer 测试。
- 将当前布尔专注状态改为 `normal / editor / preview` 三种明确状态。
- 新增 renderer 内部的自适应比例 hook／组件，通过 `ResizeObserver` 和正文变化触发重新测量。
- 使用 Electron Chromium 支持的显示缩放能力，并给缩放表面补偿布局宽度；禁止把 `zoom`、`transform` 或计算比例写进 `bodyHtml`。
- 不修改 main、preload、shared 契约、持久化格式或 Outlook 适配器。

## 验收标准

1. 宽表格在默认自动模式下缩放到 `60%～100%` 范围，编辑区和预览区分别显示自己的当前比例。
2. 切换窗口大小以及普通、仅编辑、仅预览状态时比例自动更新，页面不产生额外横向溢出。
3. 切换到“实际大小 100%”后恢复真实界面尺寸；重新启用自动模式后再次适配。
4. 极宽表格达到 `60%` 后保留局部横向滚动，而不是继续缩成不可读尺寸。
5. 在缩放后的编辑器中仍可定位文字、选择单元格和修改正文。
6. 保存后的 `bodyHtml` 与缩放前一致，不包含任何显示比例样式；Outlook 草稿行为不变。
7. 点击编辑区“展开”后只有编辑器占满主内容区；点击预览区“展开”后只有预览占满主内容区。
8. `Escape` 和按钮退出后恢复普通布局，未保存内容不丢失。

## 验证

- renderer 测试覆盖编辑区单独展开、预览区单独展开、区域切换、`Escape`、自动/100% 切换和不修改正文 HTML。
- 单元测试覆盖比例计算的上限、下限、无表格及容器变化。
- 运行邮件模板页面测试和 TypeScript 检查。
- 启动真实 Electron，粘贴宽表格后检查普通布局、编辑区单独展开、预览区单独展开、自动缩放、100% 和编辑交互；截图仅写入临时目录。
