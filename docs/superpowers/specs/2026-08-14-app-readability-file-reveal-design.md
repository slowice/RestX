# 全应用可读性与历史文件定位设计

## 目标

提高 RestX 全应用的文字可读性，并让用户在查看 AI 工具历史记录时，可以从所有展示真实来源文件的入口直接打开文件所在目录并选中文件。

本次采用固定的新字号基线，不新增字号设置，不使用页面整体缩放，也不改变窗口尺寸、数据格式或现有扫描流程。

## 字号体系

平台 renderer 样式定义统一的语义字号变量，各特性继续管理自己的布局并引用这些变量。现有承担信息传达的 `7px～10px` 文本迁移到以下档位：

- 微型标识：`10px`，仅用于状态徽标、英文眉题和不承担主要信息的短标签。
- 辅助信息：`11px`，用于路径、日期、数量、说明和次级元数据。
- 控件与正文：`12px`，用于按钮、输入框、列表摘要及需要持续阅读的内容。
- 强调正文：`13px～14px`，用于列表主标题、区块标题和主要结果。
- 页面标题及弹窗标题维持现有层级，但不得因迁移而小于正文。

正文行高同步调整到适合中文阅读的范围。图标、间距和容器不随字号等比例放大；仅在文字增大后出现拥挤或截断的组件中调整网格列宽、最小高度、换行或省略策略。

以下内容不属于可读性豁免：文件路径、会话标题、问题摘要、时间、错误信息、表单帮助、按钮文字和输入内容。装饰性字样可以使用微型标识档位，但不得承载唯一的状态或操作含义。

## 页面覆盖范围

字号基线覆盖 `src/platform/renderer/` 与当前所有 `src/features/*/renderer/` 页面。迁移以语义用途为准，不机械地给所有现有字号增加相同数值。

AI Inspector 是重点验收页面，至少覆盖：

- 工具卡片、文件夹导航和文件列表；
- Workspace 会话标题、文件路径、搜索框、搜索结果及时间；
- JSONL 标签、记录摘要、上下文、详情正文和错误状态；
- 配置查看、智能导入和 AI 分析结果。

其他页面至少检查平台导航、首页、设置、常用技能、知识图谱、邮件模板和实验室页面中现有的小字号文本，确保关键正文和控件不低于对应语义档位。

## 文件定位交互

复用 AI Inspector 已有的 `window.restx.inspector.revealInFolder(path)` 契约，不新增通用 shell API。按钮文案统一为“打开文件位置”，由系统文件管理器打开父目录并选中目标文件。

入口覆盖所有展示真实来源文件路径的历史浏览场景：

1. 普通历史、会话和日志文件行；
2. Workspace 会话列表；
3. Workspace 全会话搜索结果；
4. JSONL 历史详情标题区。

现有详情分栏不得隐藏该操作。路径文本继续显示完整值的悬浮提示；按钮放在标题附近或该行操作区，并在紧凑布局下保持可访问，不依赖只有图标的含糊入口。

## 安全与错误处理

renderer 只能提交扫描结果中已有的候选文件路径。preload 继续只暴露固定的 AI Inspector API；main 在调用 Electron `shell.showItemInFolder()` 前执行字符串校验、授权路径校验和文件存在性检查。

未授权路径必须继续被拒绝。文件被移动、删除或无法访问时，当前页面显示简短、可恢复的错误提示，不中断其他历史浏览；提示不得暴露扫描范围之外的路径或系统细节。定位入口不解析、信任或打开历史正文中出现的任意文本路径。

## 实现边界

- 字号变量属于平台稳定视觉基础，只包含语义字号，不吸收任何特性业务样式。
- 各特性只调整自己的 renderer CSS 与必要布局。
- 文件定位改动归属于 `ai-inspector` 特性；shared/preload API 保持不变，main 只收紧现有处理器的文件检查，renderer 统一入口和反馈。
- 不修改扫描结果、历史解析、Provider、持久化或其他特性的 main/preload 能力。
- 所有改动位于蓝区，不涉及黄区实现或数据。

## 验收标准

1. 全应用采用固定的新字号基线，用户可读正文、控件和关键信息不再使用 `7px～9px`。
2. 微型标识不小于 `10px`，路径、日期和辅助说明不小于 `11px`，按钮、输入及持续阅读正文不小于 `12px`。
3. AI 历史页的会话标题、问题摘要、路径、时间、标签和详情正文层级清楚，无明显文字重叠、意外截断或关键操作被隐藏。
4. 会话列表、Workspace 搜索结果、JSONL 详情及普通历史文件行均提供“打开文件位置”。
5. 点击入口后，macOS Finder 或 Windows 资源管理器打开文件父目录并选中文件。
6. 未授权路径仍由 main 拒绝；文件不存在时页面给出错误反馈，应用保持可用。
7. 字号迁移不改变业务数据、窗口尺寸、路由、扫描结果或历史解析行为。

## 验证

- 对字号变量和 AI Inspector 关键入口做聚焦的 renderer 回归检查；不为纯 CSS 数值枚举大量低价值测试。
- main 侧验证已授权文件可以定位、未授权路径被拒绝、已删除文件返回可展示错误。
- 运行受影响的 TypeScript 和现有聚焦测试，单项命令不超过五分钟。
- 启动真实 Electron，并通过独立 CDP 端口检查平台导航、首页、设置、常用技能、知识图谱、邮件模板以及 AI Inspector 的代表性状态。
- 使用隔离目录中的测试历史文件验证“打开文件位置”；截图写入临时目录并实际检查文字可读性、布局、截断和操作可见性。
