# 常用技能设计

## 目标

RestX 新增独立的“常用技能”特性。用户可以新增、编辑、删除、严格导入并执行固定提示词；执行使用当前启用的 RestX AI Provider，只产生一次文本响应。

第一版不兼容 Codex Skill，不执行命令，不使用 Agent 工具，不保留历史，也不支持参数、取消、并发或多轮对话。

## 特性边界

功能位于蓝区 `src/features/frequent-skills/`：renderer 负责列表、表单和最近结果，preload 只暴露固定方法，main 负责文件与 Provider 操作，shared 定义 DTO、错误和 channel。它不依赖其他特性的私有实现。

固定 API 为 `listSkills`、`createSkill`、`updateSkill`、`deleteSkill`、`importSkill` 和 `executeSkill`。所有 IPC 输入在触发文件或网络操作前完成校验。

## 文件模型

Markdown 是唯一数据源。每个技能保存在 `~/.restx/skills/<skill-id>/SKILL.md`：

```markdown
---
schemaVersion: 1
id: summarize-daily-work
name: 总结今日工作
description: 将内容整理成简洁的工作总结
createdAt: 2026-08-05T10:00:00.000Z
updatedAt: 2026-08-05T10:00:00.000Z
---

请生成一份简洁的工作总结……
```

ID 只允许小写字母、数字和连字符，创建后保持稳定。写入使用同目录临时文件与原子替换；目录和文件使用限制性权限。列表只扫描根目录的直接子目录，拒绝符号链接和越界路径，并按更新时间倒序返回。

## 操作流程

- 新增：填写名称、可选描述和非空提示词，系统生成不冲突 ID。
- 编辑：修改展示字段和提示词，保留 ID 与创建时间。
- 删除：用户确认后将已验证的技能目录移入系统废纸篓。
- 导入：主进程打开单文件选择器；只接受严格合法的 RestX `SKILL.md`，复制时生成新的本地 ID 与时间戳，绝不修改源文件。
- 执行：重新读取磁盘最新内容，经当前 AI Provider 发起一次文本请求。全特性同时只允许一个请求，并设置超时。
- 结果：右侧面板显示最近一次结果、状态和复制按钮；结果只存于页面内存。

## 界面

页面顶部提供“导入 Skill”和“新增 Skill”。桌面宽度下左侧为技能列表，右侧为最近结果；每行右侧放编辑、删除和主操作“执行”。新增与编辑使用弹窗，删除要求确认；窄窗口把结果区堆叠到列表下方。

## 安全与错误

文件大小、Frontmatter、字段类型、正文、ID 和时间戳均严格校验。renderer 不提交任意文件路径；导入路径只来自 main 进程文件选择器。错误映射为特性错误码，日志和界面错误不包含凭据、绝对路径、提示词或模型返回内容。

## 验收

精简自动化测试覆盖解析、CRUD、严格导入、路径和符号链接边界、IPC 校验、活跃 Provider 执行以及不并发规则。随后以隔离的 `RESTX_SKILLS_ROOT` 启动真实 Electron，实际验证新增、编辑、导入、执行、复制和删除，不接触用户现有技能。
