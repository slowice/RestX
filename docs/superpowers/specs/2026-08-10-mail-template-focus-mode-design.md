# 邮件模板专注模式设计

## 目标

解决大尺寸 Excel 表格粘贴后，正文编辑区和最终预览区过小的问题。保持表格原始字号、列宽和现有编辑能力，不通过整体缩放换取空间。

## 交互

- 在“模板内容”和“本次邮件”的标题栏提供“展开”入口；两个入口进入同一个应用内专注模式。
- 专注模式不是操作系统全屏。RestX 左侧应用导航仍保留，邮件模板页面占满右侧主内容区。
- 进入后隐藏页面说明、模板列表以及收件人、标题、JSON 等次要配置，只保留正文编辑、正文预览、操作结果通知和必要的保存／Outlook 操作。
- 编辑与预览在桌面宽度下左右并排；窄窗口沿用上下排列，避免把表格文字缩小到不可读。
- 标题栏提供“退出专注”，按 `Escape` 也可退出；退出后恢复原布局和当前滚动／编辑状态。
- 专注模式只保存在当前页面组件状态中，不写入本地存储，不改变模板数据结构。

## 布局

- 普通模式保留现有三栏页面，避免改变用户已经验证通过的工作流。
- 专注模式隐藏模板库，将工作区改为等宽的编辑／预览双栏，并让工作区高度适配当前窗口。
- 正文编辑区和预览正文取消当前较小的固定高度上限，改为占用各自面板的主要可用高度。
- 富文本工具栏保持在编辑区顶部；宽表格继续使用独立横向滚动，长正文使用纵向滚动。
- 底部保存、复制和打开 Outlook 操作保持可见，不改变“不会自动发送”的现有语义。

## 实现边界

- 改动仅限 `src/features/mail-template/renderer/`，不修改 main、preload、shared 契约或持久化格式。
- `MailTemplatePage` 管理专注模式开关和 `Escape` 监听。
- CSS 根据页面根节点的专注模式类切换可见区域、网格和高度；`RichMailEditor` 不改变表格解析、粘贴或序列化逻辑。
- 不增加拖拽分隔条、布局记忆、操作系统全屏或新的表格缩放功能。

## 验收标准

1. 点击任一“展开”按钮后，模板列表和次要配置消失，编辑与预览占满 RestX 主内容区。
2. 大表格保持原字号；超宽内容可横向滚动，长内容可纵向滚动。
3. 点击“退出专注”或按 `Escape` 后恢复普通三栏布局，未保存的正文内容不丢失。
4. 保存模板、复制富文本正文和打开经典 Outlook 的现有行为不变。
5. 桌面宽度显示左右双栏；较窄窗口不发生页面级横向溢出。

## 验证

- 增加聚焦的 renderer 回归测试，覆盖进入、`Escape` 退出和内容状态保持。
- 运行邮件模板相关测试和 TypeScript 检查。
- 启动真实 Electron，使用隔离测试数据进入邮件模板页面，检查普通模式、专注模式、大表格滚动和退出恢复。
