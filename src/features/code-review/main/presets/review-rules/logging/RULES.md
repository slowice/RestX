# 日志规范

检查敏感信息、完整请求体或响应体、日志级别不当、正常流程刷屏、同一异常多层重复打印，以及错误描述缺失或误导。字符串拼接只有导致具体泄露、错误或性能影响时才报告。

遵循自定义规则补全 CUSTOM-003：所有语言的日志和 console 只打印简明、脱敏的错误描述，不打印异常堆栈，不传入可能自动展开堆栈的异常对象，不输出 cause 异常链或手工序列化的堆栈。不得以“缺少堆栈”为由报告问题或建议补打堆栈。业务描述应足够定位操作失败，但不包含配置原文、凭据或用户隐私。

报告日志问题时必须说明可能泄露的字段或造成的运行影响，不要只给出泛泛的“建议优化日志”。
